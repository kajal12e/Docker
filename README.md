# Full Stack Docker Project (Node.js + Express + Flask)

## 📌 Project Overview
This project consists of:

- Frontend: Node.js with Express
- Backend: Flask (Python)
- Communication: Axios (HTTP Request)
- Containerization: Docker
- Multi-container setup: Docker Compose

The frontend sends form data to the Flask backend for processing.

## 🚀 How to Run the Project

### Step 1: Clone the repository

git clone https://github.com/yourusername/your-repo-name.git

### Step 2: Navigate to project folder

cd your-repo-name

### Step 3: Build and start containers

docker-compose up --build

### Step 4: Open browser

http://localhost:3000
